# xArm7 Isaac Sim 5.1 asset

Generated from `../xarm7_menagerie/xarm7.xml` with `simulation/isaac_import_xarm7.py` and Isaac Sim 5.1's MJCF importer. Keep the whole `configuration/` subfolder with `xarm7.usd` because the USD references those layers. Source meshes and license are in `../xarm7_menagerie/` (UFACTORY BSD-3-Clause license).

This is the Menagerie simulation model, not a calibrated laboratory robot or gripper. Joint axes, limits, TCP and contact behavior require checks before using it for grasp planning.
