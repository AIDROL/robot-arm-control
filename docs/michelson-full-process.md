# 从空实验区开始观看 Michelson 全流程

入口为 `simulation.michelson_experiment`。一个持续的 MuJoCo model/data 依次完成五件器件的物理抓放、底座固定、FAT 取用和侧面视觉对准、双工具头接合、镜面调整、退出和归还，最后再做光学验收。实验区起初为空，器件排列在后方备料区，FAT 放在侧前方工具位。

## 观看或重新执行

播放已经完成并验证的物理仿真轨迹，默认独立打开场景、五路相机和光学探测窗口：

```bash
./.venv/bin/python -m simulation.scene_recording --folder runs/michelson-full-demo --speed 3
```

这是记录回放：姿态来自实际动态仿真，画面标注 `RECORDED PHYSICAL SIMULATION`；相机重新渲染，光学探测图按原测量时间播放。回放不重新控制机械臂，也不将轨迹回放结果当成新的闭环验证。`--speed 1` 为原仿真时序，`--start-seconds 150` 可从 FAT 阶段附近开始；`--no-cameras` 只看三维场景。

重新执行整套物理闭环并实时观看：

```bash
./.venv/bin/python -m simulation.michelson_experiment --output runs/michelson-live --view --speed 2
```

实时仿真和回放都支持 `--speed`：`1` 原速、`2` 两倍、`4` 四倍、`0.5` 慢放。实时倍速只改变墙钟等待，不改变 1 ms 物理步长、控制器的仿真时间或光学测量周期。界面刷新按墙钟节流，避免高倍率额外堆积 4K 预览；实际速度受计算/渲染开销限制。不加 `--view` 时物理仿真按计算能力尽快运行，不做实时等待。

macOS 自动转入 mjpython，支持当前含空格的路径。重复输出目录会自动编号。各相机窗口仍显示 OpenCV 边框、角点、ID 和坐标轴；传感器不合并进主场景。主场景中的红/青线是从实际器件平面计算的两臂主光线示意，不是相机图像。

也可看输出目录中的 `full-experiment.mp4`。生成录像命令：

```bash
./.venv/bin/python -m simulation.scene_recording --folder runs/michelson-full-demo --export-video --speed 3
```

## 五件器件与布局

配置在 `configs/optical_setups/michelson_full.json`。复用已有 ArUco/STL 库的 ID，因此内部名称保留旧库存名称，光学角色由配置指定：

| 库存名称 | 光学角色 | ArUco 顶面 ID |
| --- | --- | --- |
| lens_1 | 激光源模块 | 0 |
| pinhole | 50/50 分束器 | 1 |
| lens_2 | 参考臂反射镜 | 2 |
| beam_splitter | 光学探测面 | 3 |
| mirror | FAT 可调反射镜 | 4 |

器件复用既有空心 STL、立柱和底座，光轴名义高度 100 mm。镜架和器件角色外观仍简化，库存名不表示实际装了透镜或针孔。两臂名义各 204 mm；本场景为覆盖粗装配误差使用 2 mm 腰斑、20 mm 探测视场，与原 0.5 mm/6 mm 预装台架参数不同。两个场景都保留各自配置和验收记录。

## 联通方式与假设

- 抓取位置来自全局 RGB 与腕部 RGB-D；备料槽的朝向配置为 0 rad，因此此固定备料演示使用已知槽位朝向，保留图像位置和深度修正。尚未验证任意随机朝向取料。
- 抓持和搬运通过碰撞/摩擦完成。TCP 接近容差为 0.5 mm，物体实际放置误差独立保存，不能据此声称物体达到 0.5 mm 精度。
- 下降检测到桌面支撑时停止继续压入，再等待支撑稳定后释放。释放期间启用暂定 30 N 向下吸附力代理；夹爪脱离后将底座固定在实际达到的位置和方向。没有对齐到设计坐标或改写自由物体位姿。固定后的底座采用理想刚性约束，不表示测得了真实磁力或底座刚度。
- FAT 以同一装配状态继续运行，不重置场景。镜架位姿来自装配后的新全局图像，插入时用 FAT 侧相机重复测量。两侧真实接触凹槽后驱动六角轴；工具不与镜架焊接。
- 全流程使用暂定 40 mm 六角轴、被动柔顺、可连续旋转的电机和 0.3 mN·m 旋钮静摩擦。暂定传动比仍为每旋钮弧度 0.0016 镜面弧度，均待实际 FAT 和镜架确定后标定。
- LightPipes 后端读取五件器件的实际光学平面，追踪入射、分束、两臂反射及探测面交点，再计算相干场。包含主光线口径检查；不是任意 STL 的完整非序列遮挡追迹。
- 8 个理想参考相位的 16 位探测图，经像素解调得到相对波前倾角；策略据此驱动两个 FAT 电机，不读取镜面真值误差。最初即使总功率调制可见度很小，仍可从局部条纹估计倾角。
- 接合状态下要求可见度至少 99% 且像素波前倾角小于 5 µrad，给退出扰动留余量；归还后仍要求新的可见度至少 95%，并检查 512/1024 网格结果差小于 0.5 个百分点。退出后的检测不会用退出前的结果代替。
- FAT 退出后先竖直抬高，再水平归还，以避开已摆放镜架。所有五件器件、机械臂和 FAT 的非预期接触都会导致失败。

这里使用理想相干源、理想分束比和参考相位扫描，不包括真实 PZT 驱动、偏振、探测噪声、实机标定或磁场计算。后续要实测底座刚度、卸载扰动、相机外参和螺杆传动。

## 证据文件

- `result.json` / `events.jsonl`：逐件抓放、固定、FAT 开始与整体验收时间。
- 各库存名称子目录：全局/腕部观测、真实抓放检查、放置误差、最终状态。
- `assembly-model.mjb` / `assembly-state.npz`：装配后检查点，供开发诊断明确恢复。
- `fat/optical-*`：逐次 8 相位原始探测图、测量 JSON、实际状态；`fat/result.json` 包含归还后的光学验收。
- `episode-model.mjb` / `episode.npz`：整个过程的实际状态轨迹、时间和阶段，回放器会拒绝记录中途时间倒退。

`--resume <已有运行目录>` 是显式开发恢复，使用保存的广义状态和实际底座固定位置、当前配置中的模型参数。恢复记录不会声称从空实验区重新开始。最终演示必须从零时刻完整执行，而不是拼接成功片段。

76 项自动测试通过，包含非行列目标、实际参考镜位姿影响光学、像素相位梯度反馈方向、禁止悬空底座固定、禁止轨迹时间重置，以及独立光路绘制不擦除物理场景。
