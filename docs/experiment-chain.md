# 完整机械实验链路（2026-10-29）

2026-10-31：新增三器件 JSON 布局和立柱底座，当前默认光轴高 100 mm；入口、验证及限制见 [布局适配](optical-layout-adaptation.md)。下文旧记录保留为历史数据。

**当前版本已将视觉/完整实验的五个长方体替换为用户选定的原始 STL。** 全局定位、RGB-D、夹持方向、FAT 接近方向和内部接口外参同步更新，见 [STL 集成记录](stl-integration.md)。下文原长方体的几何与 `runs/full-chain-*` 数值属于此前版本，不能当作新模型的结果。当前传感器仍各自独立窗口。

本轮按用户确认的边界集成：**五件器件摆放 → FAT 取用 → 视觉对准各镜架孔位 → FAT 放回**。不加入旋钮驱动或光学指标反馈，不开展随机 seed 精度重复试验。当前目标行仍是机械操作代理，不宣称构成有效 4f 或 Michelson 光路。

关于“动画是否代表真实联通”，见[链路因果审计](linkage-audit.md)：八项针对输入/输出依赖与失败门控的检查通过，同时明确 FAT 随动/放回仍为程序代理，不是完整物理闭环。

## 统一入口

```bash
./.venv/bin/python -m simulation.experiment --seed 7 --output runs/experiment-demo --view
```

不加 `--view` 时离屏运行。macOS 下自动调用 mjpython，支持路径含空格。默认打开机械臂主场景及五个独立相机窗口：全局 A、全局 B、末端 RGB、末端深度、FAT RGB；传感器画面不拼接、不叠在主场景中。输出目录重名自动编号。

## 连续执行

1. 仅创建并初始化一次 MuJoCo model/data。相机标定、器件标记、末端和 FAT 始终属于同一个场景。
2. 按 lens_1、pinhole、lens_2、beam_splitter、mirror 顺序操作。每件抓取前重新拍摄双全局 RGB，再到预抓取位采集末端 RGB-D、修正位置，执行夹持、抬升、转运、停稳、确认支撑、释放和验证。
3. 每阶段使用同一份 model/data，仿真时间连续增长；不会每件重置场景。已有器件继续留在目标位置，后续碰撞与视觉均包含它们。
4. STL 最终摆放绕世界 Z 转 90°，使内部通光轴平行 X 排列方向；完成后检查通光轴与有限直线的几何遮挡，再保存带布局版本的状态检查点，并从图像重新估计全部器件位姿，作为 FAT 预对准的粗目标。
5. 从配置中的已知取用位置拿取 FAT。**FAT 夹持仍是原有 mocap 随动代理，不是接触力抓取验证。** 用当前工具几何与 FK 保持其相对位姿。
6. 每个镜架到侧面预对准位后暂停，FAT 自带 RGB 相机检测对应侧面 ArUco（ID 10–14）。STL 版本记录原始 PnP，并采用已知台面高度、直立约束及图像全局 yaw，对侧面观测角点拟合 XY，再按固定标记到孔位偏移计算两个工具头的目标，更新后续轨迹；未检测到或与粗估计冲突时立即停止，没有真值回退。
7. 工具头在孔前目标位保持、轴向撤离、抬升，依次处理全部镜架，最后放回 FAT 并回位。日志中历史阶段名 `insert` 表示靠近孔前目标，**没有物理插孔**。

定位/控制目标来自图像、配置几何及机器人 FK；器件真值仅用于独立验收与接触/净空监测。FAT 相机位姿由夹爪 FK、已知 FAT 相对变换和固定相机安装关系计算，不读取镜架真值。孔位由标记到孔的已知偏移推算，没有直接识别孔边缘。

## 机械与几何边界

旧长方体版本的镜架和 FAT 几何约定如下；当前 STL 镜架使用新标定，FAT 外壳与两轴间距仍沿用代理。侧面孔位在小标记下方时，原 FAT 轴线高度会让 90 mm 外壳进入桌面，因此在本视觉场景中将两根工具轴及端点整体沿 FAT 本体 Z 下移 25 mm；保留外壳尺寸和两轴间距。该位置需机械负责人确认。历史 `fat_alignment.py` 独立演示仍使用原几何。

FAT RGB 是独立近距离针孔相机，1280 × 720、垂直视场 70°，朝 FAT 本体 +Y。它不是 D435；末端 D435 部分参数代理仍遵守约 280 mm 近距门限和约 350 mm 拍照深度。

## 验收与证据

本次以功能链路验收为主：每件器件仍要求原有接触/抬升/运输/姿态/释放稳定与 XY <10 mm 检查通过。保留精度控制器；0.5 mm 研究目标单独记录，不作为集成流程阻塞条件。初次接线时分束器为 0.534 mm，未达精度目标，记录保留而不是继续调精度。

五个镜架均须有有效 FAT 图像观测；在每个保持阶段结束时，分别检查两工具头到孔位代理中心的实际误差（现有阈值 10 mm）、工具姿态误差和原有净空/意外接触检查。不是只用运动途中某一次最小误差验收。名义工具头停距为孔前 1.5 mm，没有旋钮扭矩与光学反馈。

输出包括：

- `result.json` 与持续写入的 `events.jsonl`：全局阶段、失败原因、每件结果路径、FAT 检测与保持位验收。
- 每件器件子目录：双全局原图/检测图、末端 RGB-D、控制观测、阶段计划和误差诊断。
- `post_assembly/`：摆放后的重新定位证据。
- 每个镜架的 `*_fat_rgb.png` 与 `*_fat_detection.png`，以及 `fat-observations.json`。
- `assembly-state.npz` 和 `assembly-placements.json`：完整 MuJoCo 积分状态及已完成摆放结果，可在接线调试时直接恢复 FAT 前的同一物理状态。

```bash
./.venv/bin/python -m simulation.experiment --seed 7 \
  --resume-assembly runs/experiment-demo/assembly-state.npz --output runs/fat-resume --view
```

恢复检查点明确记录来源，不计作一次从头重跑。`--hide-fat-marker` 在 FAT 拍摄时使图像无标记，用于确认视觉失效后停在预对准位，不进入后续靠近。

集成证据：`runs/full-chain-integrated` 完成五件连续摆放并保存检查点；`runs/full-chain-fat-verified` 从该状态恢复并通过五个镜架的视觉对准/放回验收。首轮 FAT 验收发现旧代码硬编码工具头高度，随后改为按模型端点 site 评价；旧失败记录保留。另一次从头开始的最终入口检查记录于 `runs/full-chain-final`。

最终入口从零场景开始，连续运行约 260.544 秒仿真时间，`success=true`。五个放置 XY 误差依次为 0.267、0.443、0.369、0.534、0.444 mm；分束器未达 0.5 mm 研究目标的记录保留。FAT 每个镜架保持阶段结束时，两轴最大中心误差依次约 0.573、0.724、2.379、2.762、1.839 mm，全部完成侧面图像修正。返回误差为零来自 mocap 代理放回机制，不表示真实机械回位精度。

负例 `runs/full-chain-fat-vision-negative` 从已摆放检查点恢复后，FAT 无标记图像使流程在第一个预对准位停止（`FAT_MARKER_NOT_DETECTED`），没有进入 near/孔前靠近阶段。原生五路独立窗口的显示检查证据位于 `runs/experiment-five-camera-check`。

新增单元测试验证同场景复用不重置时间/状态、从图像求侧面标记位姿，以及缺失 FAT 标记不产生位姿回退；连同已有测试共 21 项。单次集成运行不是多布局成功率统计，全部结果仍为理想仿真。
