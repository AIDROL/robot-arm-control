# 五器件视觉/FAT 场景采用选定 STL

2026-10-31 更新：默认已改为 `selected_stl_post_v2`，在原外壳下增加立柱和底座，光轴高 100 mm。三器件 JSON 布局已接入抓放/FAT 链路，见 [立柱与布局适配](optical-layout-adaptation.md)。下面的 `selected_stl_v1` 标定与运行数据属于无立柱历史版本；旧检查点不能恢复到新支撑场景。

## 历史 v1 摆放方向修正

最终摆放 yaw 已改为世界 Z 轴 +90°（`x_row_yaw90_v1`），使内部镜架的局部 Y 通光轴沿世界 X 器件排列方向，侧面标记和 FAT 接合面因此朝 +X，FAT 从 +X 向 -X 接近。抓取源器件时仍按其初始图像朝向夹住两侧凹槽；没有把初始物体或执行中的位姿直接旋转。

夹爪朝向使用固定的世界向下标定矩阵，而不是把每次有残差的实际 park 朝向当作下一次标定；否则多件任务会累积约 1–3° 的摆放方向偏差。搬运阶段也加入精确朝向收敛，达到目标后才进入下降。放置验收比较实际 yaw 与 90° 的环绕角差。

摆放完成后，独立检查内部通光轴相对 X 的角差 <2°、各中心到目标直线的横向距离 <5 mm，并对这段有限直线路径做全场景几何遮挡查询。不通过时停止，不进入 FAT。该检查仅验证几何，不代表包含真实透镜、反射镜和分束器的光学传播。

检查点同时保存 `target_layout`；此前未旋转的 STL 状态会被拒绝，不能作为新布局的已完成摆放直接恢复。下文 `stl-chain-*` 的数值是方向修正前的历史记录。

新布局验证记录为 `runs/stl-yaw90-verified`：从新场景开始，五件视觉抓放、实际 90° 转向、几何贯通检查、五处 FAT 视觉对准与归还全部通过，仿真时长 266.590 s，没有恢复检查点或直接改写完成后的物体姿态。最终 yaw 依次为 90.01891°、90.00557°、90.00120°、89.98879°、89.98878°；XY 放置误差依次为 1.056、0.242、0.328、0.193、0.465 mm。首件仍未达到 0.5 mm 研究目标，记录保留。

五个通光中心到目标 X 直线的最大横向距离 0.187 mm，最大轴线角差 0.01891°，有限直线未遇几何遮挡。保存了 `beamline-geometry.json`、`yaw90-overview.png` 和 `along-optical-axis.png`。FAT 保持端双工具头最大中心误差依次为 1.474、1.383、1.527、1.451、1.326 mm，包含名义 1.5 mm 孔前停距；FAT 仍为运动代理。

37 项测试通过，新增用例会拒绝未旋转的镜架、能发现路径上的实体挡块，并防止实际回位朝向偏差污染下一件的朝向标定。`runs/stl-yaw90-chain` 保留首轮失败：动态放置本身通过 5° 机械门限，但累积朝向偏差超过新增的 2° 通光轴门限，流程因此在 FAT 前停止。修正后未放宽门限。


当前默认入口：

```bash
./.venv/bin/python -m simulation.experiment --seed 7 --output runs/stl-experiment --view
```

单件视觉抓放仍使用 `simulation.vision_pick_place`；静态标记预览使用 `simulation.stl_preview`；已知位置的独立机械验证使用 `simulation.housing_grasp`。视觉场景和完整实验默认都使用用户选定的原始 STL，不再显示五个实心长方体。全局 A/B、末端 RGB/深度、FAT RGB 仍各自独立窗口，没有相机实体示意或场景内小图。

## 感知、控制与检查同步更新

- 双全局 4K 相机采用新顶部平面高度，图像位姿用新标记偏移转换为器件中心。双机标定版本不一致时拒绝合并。
- 末端 RGB-D 保持原手眼与约 350 mm 拍摄深度，改用新顶部偏移；抓取朝向改为 X 向夹持，不沿用旧长方体的 +10 mm 高度或 Y 向夹持。
- 闭合命令为经过单件验证的 100；抬升前检查持续双侧承力接触。放下阶段汇总所有碰撞分块的台面支撑力，必要时小范围慢速下探，确认支撑后再打开夹爪。
- 验收和意外接触检查覆盖全部外壳及内部镜架碰撞分块，不只检查一个代表 geom。正常摆放不写器件位姿，也没有将器件附着到夹爪。
- FAT 标记到接口外参、接近方向及两根工具头目标按同一版本的几何计算。靠近阶段采用 0.5 mm / 0.5° TCP 收敛阈值。
- FAT 的名义孔前停距仍为 1.5 mm。内置接口实际几何的当前目标件净空下限为 0.3 mm，其他器件仍为 2 mm；原长方体版本对所有目标采用 2 mm，但旧目标 site 还位于旋钮实体面外。此处没有模拟物理插孔。

侧面标记只有 12 mm，正视 PnP 对倾角约束较弱。初次 STL 链路中，最后镜架的原始侧面姿态误差约 1.69°，沿较长的标记到旋钮偏移放大，触发净空检查。旧失败记录保留。

当前侧视定位记录原始 PnP；在器件直立于已知台面这一先验下，保留刚由全局图像估计的 yaw 和配置的标记高度，用实际侧面角点拟合 XY。仍检查 2 px 重投影误差、正深度及与粗估计一致性；缺失标记不产生位姿。该约束不适用于悬空、倾倒或高度未知的目标，不是任意 6D 精定位能力。

全部通过原有机械抓放验收，搬运期间双侧接触率均为 100%。当前仍优先完成链路，0.5 mm 研究目标单独记录；没有放宽该目标或把上述结果描述为全部亚毫米。

为避免重复五件摆放，`runs/stl-chain-fat-verified` 从同一已摆放积分状态恢复，验证修改后的 FAT 感知。恢复时仿真时间为 157.06 s，结束为 265.302 s，`success=true`。五个保持阶段结束时双工具头最大中心误差依次为 1.432、1.434、1.366、1.432、1.362 mm，包含名义 1.5 mm 孔前停距；五处均由侧面观测修正。FAT 已归还，返回零误差来自 mocap 插值机制，不表示硬件精度。

`runs/stl-chain-integration/assembly-state-stl.npz` 是给本轮较早生成的检查点绑定几何版本后的副本，积分状态数组逐项不变，版本由全部五件的已保存感知/摆放结果核对。当前入口新保存的检查点已自带 `housing_geometry`；旧长方体检查点会被拒绝，不能直接恢复到 STL 场景。当前已通过的 FAT 运行也保存了带版本的 `assembly-state.npz`。

```bash
./.venv/bin/python -m simulation.experiment --seed 7 \
  --resume-assembly runs/stl-chain-fat-verified/assembly-state.npz \
  --output runs/stl-fat-view --view
```

33 项测试通过，包括新的标记高度、凹槽抓取计划、内部 FAT 外参、侧面约束拟合、混合标定拒绝与旧检查点拒绝。`runs/stl-linkage-audit-001` 的 8 项因果检查通过：物体移动后的图像会改变抓取目标；冻结观测时不跟随真值；深度改变会改变最终抓取目标；FAT 观测改变会改变该镜架后续目标；无有效观测不能继续。审计中的干预没有作为实际机器人运动执行，也不是精度统计试验。

此次验证由连续摆放和同状态恢复后的 FAT 验证组成，不宣称是修改后从零开始的第二次成功率统计。所有结果仍属于理想相机、暂定质量/摩擦及 FAT 随动代理下的仿真。
