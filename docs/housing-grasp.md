# 选定 STL 的真实接触夹持验证

后续集成更新：该 STL 及其凹槽碰撞结构现已接入五器件全局视觉、RGB-D 与 FAT 流程，见 [STL 集成记录](stl-integration.md)。本文保留已知位置单件机械验证的具体条件与结果。

```bash
./.venv/bin/python -m simulation.housing_grasp --view
```

打开独立 MuJoCo 窗口，执行：接近已知位置 → 进入两侧凹槽 → 闭合夹爪 → 抬起 → 搬运 → 降低 → 确认台面支撑 → 松开 → 退开。结束后窗口保留结果，关闭退出。输出目录默认 `runs/housing-grasp/`，重复运行自动编号，不覆盖旧数据。无窗口检查去掉 `--view`；添加 `--record-gif` 保存动力学动画与四张接触/搬运细节图。

## 外观和接触模型

使用已选的原始 `assets/optical_housing/highousing.stl`，尺寸 72 × 64 × 108 mm，侧面 ArUco 位于平整的 -Y 上部面，夹爪沿 X 闭合到两侧凹槽。顶面与侧面标记、原 STL 网格不变。

`simulation/selected_housing.py` 配置 77 个凸接触分块：底板按原 STL 底面三角网格提取并仅在合并后仍为凸集时合并，保留底板槽孔；四角立柱保留四侧窗口；上部结构保留 X=±33 mm 的夹持面、X=±36 mm 的外沿与过渡斜面；顶部保留浅盘状凹区。原始网格只负责外观，未将整网格凸包用于碰撞。底板上很小的凸起安装卡块和顶部刻字目前只有外观，没有接触分块，不能据此验证安装操作。

整个器件是一个自由刚体，有重力、质量和由分块分布计算的惯量。质量暂定 0.120 kg；物体滑动摩擦系数 1.5，指垫系数 2.0，均沿用/基于仿真假设而非硬件测量。第一次最大闭合命令 255 的接触压入约 1.89 mm，未通过压入限制；当前命令改为 100，仍保留 Menagerie 原夹爪与执行器力限，没有增加夹持吸附力。

夹持区域原 STL 坐标为 (±33, 0, 88.1) mm，两面相距 66 mm、各内缩 3 mm。当前 `pinch_center` 沿用 Menagerie 夹爪基座下方 140 mm 的定义，模型 Home 姿态使指爪沿世界 X 开合。此测试没有沿用旧长方体的 50 mm 宽度、+10 mm 抓取高度或绕 Z 旋转 90° 的抓取方案。

## 因果链与控制边界

初始位置明确给定为世界 XY=(0.18, 0.42) m，目标为 (-0.16, 0.35) m，台面 Z=0.76 m。该阶段不进行视觉定位。笛卡尔反馈控制只驱动机器人关节及夹爪执行器，没有在运行时写入物体位姿；物体没有 mocap、焊接或夹爪附着约束。Menagerie 自带的三个 equality 只属于夹爪机构。

抬升前必须连续 0.2 s 检测到两侧指垫的承力接触。放下后使用仿真接触力确认持续台面支撑与低 TCP 速度；未获得支撑时，在最多 4 mm 范围内以 1 mm/s 下探，超时停止。支撑确认后保持实际 TCP 位姿再打开夹爪。接触力是仿真中的虚拟接触测量，尚不对应某个真实传感器。

独立验收器读取物体真值，仅用于检查，不向运动目标反馈。它检查物体与指垫的接触点确实落在凹槽面、搬运期间双侧接触、相对夹爪滑移、抬升/台面间隙、放置误差、松开后稳定性、接触压入，以及非指垫机械臂部件碰撞。机械臂碰台面或非指垫部件碰物体会立即停止。

## 当前验证结果

`runs/housing-grasp-demo/result.json` 的一次完整已知位置任务通过全部 15 项检查，运行 34.674 s 仿真时间：

| 指标 | 结果 |
| --- | ---: |
| 最大抬升净空 | 160.78 mm |
| 搬运期间双侧指垫接触 | 100% |
| 搬运期间双侧凹槽接触 | 100% |
| 搬运时相对夹爪最大平移变化 | 1.04 mm |
| 最终 XY 放置误差 | 0.90 mm |
| 最大接触压入 | 0.64 mm |
| 最小包络底面/台面间隙 | -0.13 mm |
| 结束后松开、台面支撑稳定时间 | 2.0 s |
| 不期望的机械臂碰撞 | 0 |

保存了 `grasp.gif`、`lift-detail.png`、`transfer-detail.png`、`lower-detail.png`、`retreat-detail.png`、事件与轨迹 JSON。截图文件名对应进入该阶段时的状态，例如 `transfer-detail.png` 展示抬升完成后的夹持状态。

3 项新增接触模型测试验证四侧窗口物理可穿过、凹槽内缩空间未被凸包填平、自由体在重力下落到台面并由接触支撑。完整测试集 27 项通过。渲染与录像使用同一控制配置，不是新的精度统计样本。

以上记录单件、已知位置的机械验证条件，不代表真实硬件精度。后续已将该 STL 接入双 4K / RGB-D 和完整五器件流程，并同步更新尺寸、标记/夹持外参与高度先验，见 [STL 集成](stl-integration.md)。内部可调运动、FAT 实际驱动与光学传播仍未实现。
