# 光学探测反馈接口

本阶段补齐独立探测窗口和观测接口，未实现位置调整或 FAT 机构闭环。

## 数据链

LightPipes 探测面强度 → 固定线性增益/16 位量化 → 像素图 → 功率、质心、总通过率、有效性。强度满量程为 1200 W/m²，当前没有暗电流、读噪声或真实曝光模型。功率由像素值还原强度后乘像素面积积分，质心由同一像素图计算，不读取元件目标位置来生成观测。

总通过率使用配置的输入光功率作为参考；不是双路真实功率计实测。针孔局部透射比另作为 `model_pinhole_local_transmission` 诊断字段，明确标为 MODEL：它来自 LightPipes 孔径前后功率比，不能冒充末端相机独立测出的针孔透射。

窗口只显示单个光学探测面，不合并全局/腕部/FAT 视图。图像采用固定对数色阶便于看弱光，所有指标仍来自线性量化像素，没有逐帧自动归一化以掩盖功率下降。

## 有效性

`observation.json` 包括 capture_id、仿真/墙钟时间、坐标系、像素间距、线性增益、功率、质心、通过率、valid 和 reasons。规则区分无信号、非有限或负强度、饱和及传感器边缘截断。有效观测仍可能不满足光学任务的通过率门限。

将来控制器读取时须调用 `usable(observation, now_simulation_s)`，拒绝失效、未标时、未来或过期的观测。窗口不会把重复显示同一文件计为新测量：watch 模式显示近期更新或 HELD FRAME；静态查看明确写 SAVED OBSERVATION。

发布顺序为图像原子替换后提交 JSON，JSON 绑定预览 SHA-256；读取遇到不匹配会等待，不混用新旧图像。只保留最新帧文件。

## 入口

光学验证自动生成 `design-detector/` 与 `actual-detector/`，其中包含 detector16.png、preview.png 和 observation.json。

查看本轮已保存实际观测，无需重复抓放：

```bash
./.venv/bin/python -m simulation.optical_sensor \
  --folder runs/optical-detector-verified/actual-detector
```

加 `--watch` 可在同一窗口接收该目录后续发布的新观测；Q/ESC 关闭。完整实验使用 `--optics-spec ... --view` 时，会在光学计算完成后自动打开第六个独立窗口。关闭主场景时回收该进程。

目前实验仍在装配后进行一次光学计算，窗口按新计算结果更新，不会随渲染帧伪造测量，也没有每帧重算 FFT。后续位置调整闭环需要在每次真实动作后重新计算并发布。

## 本轮验证

`runs/optical-detector-verified` 使用已有装配快照：实际观测 valid=true，功率约 96.514 µW，总通过率约 9.6514%，质心 Y/Z 约 (-0.1237, -0.0448) mm；光学任务仍不通过。设计观测同样有效，通过率约 99.584%。

51 项测试通过；新增测试覆盖像素积分/偏心、无信号、NaN、饱和、边缘截断、陈旧时间戳和预览文件损坏。独立原生窗口完成短时显示验证；没有重跑机械装配，也未宣称位置调整或旋钮反馈已经完成。
