## 实现边界

`simulation/isaac/isaac_michelson.py` 是分阶段入口，`simulation/isaac/isaac_michelson_backend.py` 构建原生 USD 刚体、复合碰撞体、有限力关节驱动和 PhysX 接触报告。MuJoCo 只读取仓库的机械资产描述，并由读回的 PhysX 关节状态计算独立 FK / Jacobian；该后端不调用 MuJoCo 动力学步进或使用其接触作为验收依据。后续新增了[相机与调光监视器](isaac-camera-optics-view.md)，验证运行的原始文件和哈希保持原样。

- 原始 STL 的视觉形状与分块凸碰撞体分开保留，沿用抓持凹槽、立柱、底座和 ArUco 布局，未以整个镜架的封闭凸包替代。
- 全局定位使用 Isaac 图像中的标记角点和标定桌面/顶标平面；固定备料槽朝向为 0 rad。腕部使用 Isaac 的 RGB 与原生 optical-Z 米制深度，并复用仅接收像素、深度与外参的估计器。该传感器仍是理想 RGB-D 代理。
- 抓持和搬运由 PhysX 的摩擦/接触完成。支持接触稳定后，释放阶段沿用原模型的 30 N 向下吸附代理；夹爪脱离后在实际达到的位姿启用底座固定，不修改物体位姿对齐目标。这是暂定吸附力和理想底座固定，无实测磁场或磁座刚度。
- 镜面与旋钮使用 PhysX mimic 约束，保留 0.0016 rad/rad 暂定传动比。PhysX 要求参考旋转关节的有限范围，因此旋钮设为 ±12.5 rad，对应原镜面 ±0.02 rad 行程。旋钮 0.3 mN m 静摩擦用有限扭矩、弹塑性参考点的被动摩擦近似，尚需机构独立验证。
- 关节链显式设置 64/8 次位置/速度求解迭代。自碰撞启用，按源模型保留父子刚体及明确的四连杆碰撞排除。
- `michelson_assembly_optics.from_poses` 接收实际光学平面，保持原 LightPipes 强度、16 位曝光、相位扫描、像素梯度策略和 95% 归还后门限。引擎间接口已测试，不以设计目标替代实际位姿。
- `physx-trajectory.npz` 保存实际关节和刚体状态；后续运行另保存逐步接触遥测。`source/`、`configuration.json` 和 `provenance.json` 绑定各次运行源码与配置。`--resume` 是显式开发恢复，不计作从空实验区执行。
