# 放置误差分解（2026-10-29）

本轮只加入被动诊断，没有调整速度、控制增益、阶段容差、摩擦或夹爪动作。固定 seed 7 的完整抓放验收通过，新增两个独立手算样例测试通过，共 15 项测试通过。

后续已完成[停稳与缓慢张爪对照](placement-settling-comparison.md)：seed 7 张爪位移从 3.389 mm 降至 0.928 mm，最终 XY 误差从 1.920 mm 降至 1.085 mm。使用 `--placement-strategy settled` 启用，原流程仍保留为默认基线。

## 使用

```bash
./.venv/bin/python -m simulation.vision_pick_place --seed 7 --output runs/placement-error
```

可添加 `--view` 观看；四路传感器仍分别显示。每次运行现在额外保存：

- `error-breakdown.json`：各阶段末端误差、向量误差预算与最大夹持相对漂移。
- `error-breakdown.md`：可直接阅读的阶段与误差表。
- `diagnostic-trace.json`：每 0.1 秒及阶段切换时的 TCP、器件位姿和目标，仿真真值仅供诊断，不供控制。

## 测量定义

TCP 到位误差在阶段切换的实际仿真状态采样，与刚结束阶段的目标比较，而不是用下一阶段目标或插值过程中的最大误差。

夹持基准在闭合结束、开始抬升时建立，记录器件中心在实际 TCP 坐标系下的位置。从该时刻到开始松爪时的变化称为净夹持相对变化；单独记录过程最大变化。该指标包括柔顺、运输与下降接触，不单独证明摩擦滑移。

释放位移从开始张爪到最终静止计算，另分为张爪阶段和张爪完成后的撤离/静止阶段。

最终位置误差以带符号世界坐标向量拆成：配置几何偏移 + TCP 平移误差 + TCP 姿态的杠杆效应 + 初始夹持注册偏差 + 夹持相对变化 + 开始松爪后的器件位移。向量和精确闭合；每项 XY 模长不能相加，也不等同于因果贡献百分比。Z 向配置偏移包含故意留出的放置间隙。

## seed 7 结果

本地证据：`runs/placement-error-seed7`。13 项抓放验收通过。

| 指标 | 数值 |
| --- | ---: |
| 末端 RGB-D 位置误差 | 约 0.080 mm |
| 抓取下降完成时 TCP 三维误差 | 4.987 mm |
| 开始松爪时 TCP XY 误差 | 2.429 mm |
| 初始夹持注册偏差折算 XY | 1.040 mm |
| 从夹紧到松爪的净相对变化折算 XY | 0.138 mm |
| 转运期间最大相对漂移（三维） | 1.853 mm |
| 抬升至开始松爪的最大相对漂移（三维） | 2.907 mm |
| 松爪过程器件 XY 位移 | 3.389 mm |
| 松爪完成后器件 XY 位移 | 小于 0.000001 mm |
| 最终物体 XY 误差 | 1.920 mm |

开始松爪时 TCP 误差向量为 `[-1.7715, +1.6617] mm`，松爪导致的器件位移为 `[+2.5047, -2.2836] mm`，方向部分抵消，因此最终误差不能理解为 2.429 + 3.389 mm。预算闭合残差约 1.6e-17 m。

这一次运行中，释放后的新增位移主要发生在张爪阶段，而不是机械臂撤离之后。这支持下一轮优先对照测试“下放结束先停稳/确认落座，再分步松爪”，并分别收紧抓取与放置 TCP 终点误差。当前阶段容差为 5 mm；不能将理想相机约 0.08 mm 的定位误差等同于整条操作链的精度。

上述是单个固定 seed 的诊断，不代表跨 seed 稳定性或真实硬件结果。下一轮只改变一类控制参数或动作策略，用相同 seed、同一套测量比较，避免多项同时调整后无法归因。
